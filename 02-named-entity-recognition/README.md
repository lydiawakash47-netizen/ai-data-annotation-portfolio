Project 02: Named Entity Recognition (NER)

Project Overview

This project demonstrates my practical experience identifying and labeling named entities in text using Label Studio.

Project Details

Annotation Type: Named Entity Recognition

Tool: Label Studio

Dataset Size: 50 text samples

Tasks Completed: 50/50

Entity Categories: PERSON, ORG, LOC, DATE, MONEY

Evaluation Method: Exact-match entity-level assessment

Practice F1 Score: 96.92%

Annotation Workflow

Created a Named Entity Recognition project in Label Studio.

Configured five entity labels.

Imported the 50-task practice dataset.

Highlighted named entities and assigned appropriate labels.

Exported completed annotations.

Compared annotations against a reference answer key.

Quality Assurance Results

Correctly identified entity spans: 189

Total predicted entities: 195

Total reference entities: 195

Precision: 96.92%

Recall: 96.92%

F1 Score: 96.92%

These results are from a practice assessment rather than an official employer evaluation.

Challenges and Lessons Learned

The quality review identified opportunities to improve entity-boundary accuracy and completeness.

Examples included:

Recognizing complete organization names.

Avoiding unnecessary words in entity spans.

Including all characters in an entity name.

Identifying all relevant date expressions.
