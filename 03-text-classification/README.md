# Text Classification and Topic Labelling

## Project Overview
This project demonstrates practical AI data annotation using Label Studio. The objective was to classify 50 text samples into five predefined categories.

## Project Details
- Tool: Label Studio
- Annotation Type: Single-label Text Classification
- Tasks: 50
- Categories: Finance, Healthcare, Education, Travel and Sports

## Annotation Process
1. Created the project in Label Studio.
2. Configured five classification labels.
3. Imported 50 text samples.
4. Assigned one topic label to each sentence.
5. Completed all annotation tasks.
6. Exported the dataset for quality assurance.

## Quality Assurance
The project contains 50 completed annotations. The QA results will be documented in a separate report after verification against the reference answer key.
