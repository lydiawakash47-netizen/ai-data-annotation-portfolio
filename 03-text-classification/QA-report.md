# Text Classification and Topic Labelling — Quality Assurance Report

## Project Overview
This project involved classifying 50 text samples into five categories using Label Studio: Finance, Healthcare, Education, Travel and Sports.

## Annotation Methodology
1. Configured five topic labels in Label Studio.
2. Imported 50 practice sentences.
3. Assigned one category to each sentence.
4. Completed and exported all 50 annotations.
5. Prepared the dataset for quality assurance against a reference answer key.
