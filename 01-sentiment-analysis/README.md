# Project 01: Sentiment Analysis

## Project Overview
This project demonstrates my practical experience in sentiment classification using Label Studio, following my DataLens training.

## Project Details
- Annotation Type: Text Classification
- Tool: Label Studio
- Dataset Size: 10 text samples
- Categories: Positive, Negative, Neutral
- Tasks Completed: 10/10
- Reference Agreement: 90% (independent practice assessment)

## Annotation Workflow
1. Imported the CSV dataset into Label Studio.
2. Configured three sentiment labels.
3. Read and classified all 10 text samples.
4. Exported completed annotations.
5. Reviewed results against reference labels.

## Skills Demonstrated
- Sentiment classification
- Label Studio configuration
- Annotation consistency
- Quality assurance
- CSV dataset management

## Challenges and Lessons Learned
I learned to distinguish neutral statements from subtle positive expressions. For example, 'The weather is nice today' expresses a positive evaluation through the word 'nice'.

## Next Steps
Practise sarcasm, mixed sentiment, and ambiguous language using larger datasets.
